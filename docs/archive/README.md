# Archive — plans that are finished

Work orders whose every item is ticked. They are kept rather than deleted
because each one records *why* something was built the way it was, and that
reasoning is the part a future change needs — the sequence of decisions, the
traps found on the way, the options deliberately rejected.

**Nothing here is live work.** A tracker in this folder describes shipped code.
If it disagrees with the code, the code is right and the file is history — see
[`docs/RULES.md`](../RULES.md) on docs following code rather than the reverse.
